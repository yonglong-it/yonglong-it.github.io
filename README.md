# Yonglong Li — Academic Homepage

Personal website: https://yonglong-it.github.io/

Research, biography, and publications for Yonglong Li at Xi’an Jiaotong University.

## Update the homepage

- Edit `index.html` on GitHub to change the biography, research descriptions, contact links, or publication entries.
- Edit `styles.css` to change colors, typography, or layout.
- Commit changes to `main`; GitHub Pages deploys that branch from the repository root.
- Keep `.nojekyll` in the repository to serve the static files directly.

This site uses plain HTML and CSS. It requires no dependencies, build step, or JavaScript. Conference papers can be expanded using the built-in disclosure control.
